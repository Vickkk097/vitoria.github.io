# Imagens

Esta pasta fica reservada para imagens locais otimizadas do projeto. As páginas atuais usam imagens externas do Unsplash, com textos alternativos (`alt`) definidos no HTML. Quando imagens locais forem adicionadas, devem ser armazenadas aqui e referenciadas com caminhos relativos, por exemplo `imagens/acao-comunitaria.webp`.
