# Projeto em destaque: Plataforma de Hospedagens e Viagens

Projeto acadêmico desenvolvido durante o curso intensivo de Computer Programming da Estação Hack MasterTech.

## Objetivo

Desenvolver uma plataforma web para pesquisa de hotéis e hospedagens, centralizando informações para facilitar a busca e a comparação de opções pelos usuários.

A aplicação foi inspirada em funcionalidades de plataformas como Trivago e Airbnb, permitindo consultar hospedagens, aplicar filtros por preço e características da estadia, visualizar kits de viagem e entrar em contato com responsáveis pelos imóveis.

## Funcionalidades

- Consulta de hotéis e hospedagens
- Filtros por preço e características da estadia
- Exibição de informações sobre acomodações
- Visualização de opções de kits de viagem
- Contato com o responsável pelo imóvel
- Interface organizada para melhorar a experiência do usuário

## Tecnologias utilizadas

- **HTML:** estruturação das páginas
- **CSS:** estilização e organização visual
- **JavaScript:** interações e lógica de filtros
- **PHP:** conceitos de desenvolvimento back-end
- **Java e Python:** apoio aos fundamentos de programação
- **Banco de Dados:** organização das informações de hospedagens
- **Git e GitHub:** versionamento e colaboração

## Aprendizados

Este projeto permitiu aplicar conhecimentos técnicos em uma solução prática e compreender etapas importantes do desenvolvimento de software, como identificação de necessidades, planejamento, desenvolvimento, testes e melhorias.

Também fortaleceu habilidades em desenvolvimento web, lógica de programação, organização de dados, resolução de problemas, comunicação e trabalho em equipe.
